## Decisions

- D-08 (CI layout): the workflow file lives in `.github/workflows/` (a dot folder Archon skips); each of the four accepted `coverage.commands` appears in it verbatim and the jobs `tests`, `fixtures` and `lint` are named in it; `.github/cadence/coverage-report-check.mjs` is copied in from Cadence's template and tracked. Evidence: `testing-policy.mjs:118-126,221-237`, `git ls-files .github`, `docs/reference/archon/global-workflows.md:52`.
- D-09 (coverage shortfall): the shortfall closes with characterization tests for `fence/checks.py` (0% of 84 statements on 2026-11-08; in-scope about 69% lines, 79% branches), exempt from the red-run rule; no threshold lowered, nothing excluded. Evidence: `uv run --no-project --with 'mcp>=1.2,<2' --with pytest --with pytest-cov pytest -q --cov=fence --cov-branch --cov-report=term fence` (71 tests), `docs/testing.md` rule 8.
- D-10 (CI verification): AC2 is verified at /cad-verify: the owner is asked in that turn to push the branch to `ohshitgorillas/gauntlet` so Actions runs, and the result is read from the check runs on the commit. Evidence: `CLAUDE.md` 4.4, `.planning/config.json` (`forge_provider: github`). Owner's answer 2026-11-08.
- D-11 (fence `commit` scope): Phase 2 builds only `commit` under `FENCE_COMMIT=1` with path recording; the rest of writing-design step 1 goes to Phase 6. Evidence: `writing-design.md:57-75,649`, CORE-03.
- D-12 (name patterns): an entry holding `*`, `?` or `[` is a pattern, matched segment by segment with `fnmatchcase` at equal segment count, in READ, WRITE, DENY, ONCE and COPY; folder entries keep their prefix meaning; for a pattern entry, `list_directory` and `find_files` show a folder only when it holds a readable file. Evidence: `plan-review-design.md:53-66`, `spec-review-design.md:14`, `fence/files.py` (`_inside`, `_visible`), `landing-design.md:549`.
- D-13 (`FENCE_HIDE`): reuses `_folders` (patterns included); every tool, `commit` included, refuses a hidden path with `PermissionError(f"{path}: hidden (FENCE_HIDE)")`; list, find and grep never show a hidden path or a folder holding only hidden paths; unset hides nothing; only the coder's fence sets it (D-89/D-13 of Phase 1). Evidence: `gauntlet-design.md:424-440`, `writing-design.md:414`, `runtime-model-design.md:139`.
- D-14 (file length): the extensions keep `fence/files.py` under the 500-line filepawl cap; `commit` with its lock and retry may live in a sibling `fence/` module that `files.py` registers. Evidence: `pyproject.toml` `[tool.filepawl.length]`, `fence/files.py` (275 lines).
- D-15 (`rounds.py`): implements every mode and field of `runtime-model-design.md` "Hearing state" and "Ledger", including `first` for several hearings in one folder (Phase 1 D-62/D-67) and `next` `vacant` at the twelfth leading review (D-109), bounds from "Loop shape and bounds"; the suite drives `main` through a test `Profile` and real files. Evidence: `spec-review-design.md:62-118`, `runtime-model-design.md:11-66`.
- D-16 (`red.py`): exposes `cut`, `listing` and `red(run, brief, head="")`; texts start `exit=<n> timed_out=<true|false>`; only lines beginning `PASSED <id>`, `FAILED <id>` or `ERROR <id>`, cut at the first ` - `, are results; standard library only. Evidence: `gauntlet-design.md:401-422`, `writing-design.md:43`, `worktree-cut-design.md:193`.
- D-17 (suites): every new suite goes red against a null stub before the code (`docs/testing.md` rule 8); suites run as `uv run --no-project --with <deps> --with pytest pytest -q fence` and `... pytest -q .shared/tests`, loading modules through `importlib` as `fence/files_helpers.py` does. Evidence: `docs/testing.md`, `fence/files_helpers.py`, `gauntlet-design.md:422`.
- D-18 (lint job): runs `uv sync` then `.venv/bin/pre-commit run -c .pre-commit/config.yaml --all-files`; filepawl v0.11.0 installs from its public GitHub URL. Evidence: `pyproject.toml`, `.pre-commit/config.yaml`, `CLAUDE.md` section 5; owner's answer (public).
