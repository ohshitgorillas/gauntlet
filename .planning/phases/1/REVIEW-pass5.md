**5.01** `runtime-model-design.md:142` (also `:140`), row H54. New (G-128/D-104 ruled that the mend saves and restores a mender's uncommitted edits; no group rules what counts as a mender's uncommitted edit). Medium. Group G-129.
Text: "When `git status --porcelain` (`gauntlet/` excluded) is not empty and the owner has not ended the repair, `pose` first writes the uncommitted changes as ... The mend runs one mender at a time, so every uncommitted change is that mender's own. The case is `commit-failed`", and at `:140` "so every uncommitted change is the wave's own".

The owner can only `leave` or `back-to-planning`, though the mend is green and committed. Writing has the same premise (`:140`): node `test` runs the brief command in the tree, and `clean` of the next cut's blocks marks every block `blocked` on that file (`writing-design.md:336-339`), one false amicus turn per cut.
