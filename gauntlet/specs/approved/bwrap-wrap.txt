1. For a Bash call from any agent but the two blind ones, `.claude/hooks/bwrap-wrap.py` answers with an `updatedInput` whose command is a `bwrap` invocation carrying the caller's command text unaltered, whatever that text is. A payload whose command is `echo hi; cat /etc/hostname` and one whose command is `echo $(cat /etc/hostname) <<'X'` both come back wrapped, and the caller's text appears in the replacement byte for byte.
   kills: a hook that parses the command to decide how to wrap it — quoting it per shape, refusing a heredoc, rejecting a command substitution — denies or mangles the two commands above, the way `.claude/hooks/shell_shapes.py:422` denies a heredoc whose body quotes a lane path.
   bite: null stub fails at `echo hi; cat /etc/hostname` (surface new); `ls .claude/hooks/bwrap-wrap.py` returns `No such file or directory`.
   existing: none, `grep -rn 'bwrap' tests/` returned no output.

2. The worktree binds are built from what exists at call time. With two trees under `.claude/worktrees/`, the invocation binds `.claude/worktrees` read-only and both trees writable; with none, it binds no tree and still wraps; a tree removed between two calls appears in the first invocation and in neither the second nor as a stale bind.
   kills: a hook that caches the tree list, or that binds a fixed `.claude/worktrees/*` glob expanded once, fails the `bwrap` invocation outright the first time a tree is removed, so every Bash call in the session errors until the session restarts.
   bite: null stub fails at two trees present (surface new).
   existing: none, `grep -rn 'bwrap' tests/` returned no output.

   existing: none, `grep -rn 'bwrap' tests/` returned no output.
