> Add scripts/gates/symbol-closure.py: an AST scan of tests/ that takes symbol names and returns the test files that import or reference them, one transitive hop through tests/support, file granularity and no arity analysis, with a --self-test and an entry in scripts/gates/check-gates.sh.
> the block should pin the closure's behavior and not the gate wiring

surface: `scripts/gates/symbol-closure.py`, invoked as
`printf '%s\n' <symbol>... | scripts/gates/symbol-closure.py --symbols-stdin <anchor>`.
The symbols arrive on stdin, one per line. The one argument is an anchor path, and the
directory it sits in is the scan root; every `*.py` file under that root is read. Output
is one path per line on stdout, sorted, each path written relative to the parent of the
scan root, and the exit code is 0 whether the set is empty or not. It is a fact reporter,
not a gate.

Each line below builds its own tree outside the checkout and anchors on
`<abs>/tests/__init__.py`, an empty file. The command and the symbol set are identical
across a line's two runs and only the contents of the tree differ, so the two expected
outputs are two observations of one invocation.

1. For the symbol set `alpha` over a tree whose `tests/test_one.py` reads
   `from pkg import alpha` and calls `alpha()`, run twice: where `tests/test_two.py`
   reads `import beta` and calls `beta()`, stdout is `tests/test_one.py`; where that same
   `tests/test_two.py` instead calls `alpha()` and imports nothing at all, stdout is
   `tests/test_one.py` then `tests/test_two.py`.
   kills: collects the names in `Import` and `ImportFrom` statements and nothing else, so
     a test file that takes the symbol in as a fixture argument and calls it by bare name
     never reaches the closure the reviewer is handed
   bite: null stub fails at both runs (surface new) — a script whose scan returns the
     empty set prints nothing, and the first run expects `tests/test_one.py`
   existing: none, `grep -rln "symbol_closure\|symbol-closure" tests/` prints nothing and
     exits 1
