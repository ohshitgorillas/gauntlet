surface: `scripts/strike-diff.py`, invoked as
`python3 scripts/strike-diff.py --spec <path> --base <rev> --head <rev>`, one line
per target on stdout.

1. For a block line striking `tests/test_a.py::test_x`, the target's stdout line is
   `OK tests/test_a.py::test_x` at a head where that test name is absent from
   `tests/test_a.py`, and `UNSATISFIED tests/test_a.py::test_x` at a head where the
   name is present and the line's quoted `assertion:` text is inside that test's body.
   kills: reports `OK tests/test_a.py::test_x` whenever the test name is present, so a
     test that kept the offending assertion it was struck for passes the merge
   bite: null stub fails at the second head (surface new)
   existing: none, `ls tests/` -> no such directory

2. With the line's quoted `assertion:` text present in a sibling test of
   `tests/test_a.py` but absent from `test_x`'s own body, the target's stdout line is
   `OK tests/test_a.py::test_x`.
   kills: greps the whole file for the assertion text and prints
     `UNSATISFIED tests/test_a.py::test_x` on a file where a parametrize case carries
     the same assertion line
   bite: null stub fails at that head (surface new)
   existing: none, `ls tests/` -> no such directory

3. At a head where `tests/test_b.py` still exists and differs from base, the
   `tests/test_b.py` stdout line is `UNSATISFIED tests/test_b.py` when the block
   carries a whole-file line naming it, and `UNNAMED tests/test_b.py` when the block
   names only `tests/test_a.py`.
   kills: prints a fixed `UNNAMED` line without reading the diff, so the run whose
     block names `tests/test_b.py` reports it unnamed too
   bite: null stub fails at both runs (surface new)
   existing: none, `ls tests/` -> no such directory

4. For a spec line whose `as:` names `tests/test_a.py::test_x_renamed`, the stdout line
   is `OK tests/test_a.py::test_x_renamed` at a head defining a test of that name and
   `MISSING tests/test_a.py::test_x_renamed` at a head defining no such test.
   kills: prints `MISSING` for every `as:` name without reading the head, so the head
     that carries the replacement is reported as lacking it
   bite: null stub fails at both heads (surface new)
   existing: none, `ls tests/` -> no such directory
