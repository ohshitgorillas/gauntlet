# Gatesmith scaffold step

## The step

A `scaffold` brief has you bring the scaffold to what your row says today, whatever an earlier scaffold left behind.

## What you read

On a `scaffold` step `docs/design.md` §8, for the CLI module the console script points at.

## Scope

`scaffold`: the word alone; scope: `pyproject.toml`, `uv.lock`, `Makefile`, `.gitignore`, `.pre-commit-config.yaml` and the hook.

## Step 5

Scaffold step: take in turn each clause of your row's `scaffold` sentence, and each clause of your row or its Decisions bullets that says what a file in the scaffold's scope must or must not hold.

Read the file the clause governs; the clause on ignores, excludes and overrides governs checker configuration, never `.gitignore`; which paths a tool `make check` runs writes is settled at step 7, never guessed.

A file that meets it stays untouched (`met`); one that does not is changed until it does (`written`); a clause that governs no file in your writes is `outside writes`.

A clause is `open`, and goes on `OPEN`, only when meeting it needs a path outside the scaffold's scope; a value it needs that no document states is yours to choose under the choice rail below, and the clause it serves is `met` or `written` like any other.

A change that fails a gate is never `open`, and step 7 holds it.

"Pre-commit installed" is met only when `.pre-commit-config.yaml` holds a hook whose entry is `make check`, and the hook holds pre-commit's `File generated by pre-commit` line, `--config=.pre-commit-config.yaml`, and an `INSTALL_PYTHON=` line whose path ends in `/.venv/bin/python` and which `ls -l` on that path shows exists.

The hook is shared, so the checkout whose `.venv` it names need not be this one.

A missing config hook is written into `.pre-commit-config.yaml`.

Run `uv run pre-commit install` only when the hook is absent, or was generated by pre-commit and misses one of those lines; when it exits nonzero, the clause is `open` and its `OPEN` line quotes the error line.

A hook pre-commit did not generate stays untouched, `foreign`, on `OPEN`.

Then run `uv sync` and `ls -l .venv/bin/gauntlet`.

When `uv sync` exits nonzero or `ls` prints `No such file`, the row's console-script clause is not met: fix `pyproject.toml` and run both again.

When the error names a path outside the scaffold's scope, or the second run prints the same error line, that clause is `open`, its `OPEN` line quotes the error line, `CHECK` reads `NOT INSTALLED`, and you go to step 8.

## Step 7

On a scaffold step then run `flock /tmp/gauntlet-heavy.lock nice -n 19 ionice -c3 uv run pre-commit run --all-files`, whose `make check` line shows that pre-commit invokes the gate.

## Rails

On a `scaffold` step each such value a file in its scope already holds goes on `CHOSEN` and never on `OPEN`.
