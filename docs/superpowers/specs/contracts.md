# Cross-design contracts

This is the contract inventory of the seven designs in this folder: `gauntlet-design.md`, `gauntlet-intake-design.md`, `plan-review-design.md`, `spec-review-design.md`, `worktree-cut-design.md`, `writing-design.md` and `landing-design.md`. A row is a contract that two or more designs name, and it cites every design that names it. A thing one design alone names is not a row. The exception is the six Archon features the roadmap names, which are rows whatever their design count. The inventory records what each design states. It carries no finding, and no verdict except the verdict column of section A. Judging a disagreement is the review's work.

**Citation form.** `<design>.md:<line>`, using the file name as it sits in this folder, one citation per naming design and line. A cell that holds two designs' values holds each beside its citation, so a disagreement is visible in one row. A value of `-` means the design cited for the row's other cells states nothing for that cell.

**Row ids.** Each row carries a stable id. The letter names its section: H node references and hand-off fields, P paths, F fences, S scripts, R roles, A assumed Archon features. The number runs within the section and is never reused. Findings and rulings cite a row by id.

**Citation age.** The citations of a row a pass-1 ruling did not change were taken from the designs as committed at `0d08176`; the ruling commit (`docs(1-3): apply the pass-1 rulings`) moves lines in all seven designs. `git show 0d08176:docs/superpowers/specs/<design>.md` gives the cited line. Rows a ruling changed state the ruled value and cite it by section or node id, the line numbers being the ruling commit's. The owner-control commit (D-81, `docs(1-5): apply the owner-control ruling`) moves lines in all seven designs again: every row it rewrote or added cites by heading or node id, and a row it left alone keeps the older line citations above.

**Seed.** A row seeded from a bullet of the gauntlet design's copy list ("The phase designs contain these copies:", `gauntlet-design.md:23-34`) carries `seed:Bnn`, `nn` being the bullet's position in that list. The bullets are claims to check, not ground truth: the seeded citations are the lines that name the contract today, read in each design.
