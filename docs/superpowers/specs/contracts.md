# Cross-design contracts

This file is the index of homes of the eight specs in this folder: `gauntlet-design.md`, `gauntlet-intake-design.md`, `plan-review-design.md`, `spec-review-design.md`, `worktree-cut-design.md`, `writing-design.md`, `landing-design.md` and `runtime-model-design.md`. A row names one contract that two or more specs name, its one home (a file, and a heading or node id inside it) and every spec that names it. It holds no value: each rule and value lives in its home alone, and every other place points to the home (owner ruling D-98 (2); D-61, D-63). A thing one spec alone names is not a row. The exception is the Archon features the roadmap names, which are rows whatever their spec count. Section A also holds the verdict on each Archon feature, because this file is the verdict's home (D-03, AC4).

**Citation form.** A citation names a file and a heading or a node id, never a line number (D-61). A node id is the id in the YAML sketch of the design that homes it.

**Row ids.** Each row carries a stable id. The letter names its section: H node references and hand-off fields, P paths, F fences, S scripts, R roles, A assumed Archon features. The number runs within the section and is never reused or renumbered. Findings and rulings cite a row by id.

**Seed.** A row seeded from a bullet of the gauntlet design's copy list (`gauntlet-design.md`, the list under "The copies the phase designs once held, each resolved") carries `seed:Bnn`, `nn` being the bullet's position in that list. The bullets are claims to check, not ground truth.

**The model rows.** Rows whose home is `runtime-model-design.md` (H27 to H29, H33, H38, H52 to H55, P7, P20, S7 for what it answers, A15, A16, A18, A22) have their rule and value in that file's headings "Hearing state", "Ledger", "Loop shape and bounds", "Resume and rerun" and "Commit model".
