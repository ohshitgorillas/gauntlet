Surface under test: the wire surface of the PreToolUse lane hooks in .claude/hooks/. One JSON object on stdin carrying `tool_name`, `tool_input` and `cwd`, and the hook answers on stdout with either nothing at all, written SILENT below, which is the call being allowed, or a JSON object whose `hookSpecificOutput.permissionDecision` is `deny`, written DENY below. The hooks are invoked as `python3 <hook dir>/<hook>.py` with the payload on stdin and `cwd` set to the root of the checkout the copies were made from, discovered rather than typed. A second variable is the hook directory's own sibling configuration file `blind-reads.json`, which a payload cannot carry: each line below runs one family of payloads against copies of `.claude/hooks/` that differ only in that file, and its outcome is the set of payloads whose answer differs between two copies, written "the changed set" below. A copy is the whole directory, so a hook keeps the siblings it imports. `BARE` is a copy carrying no `blind-reads.json` at all. `TESTS` is a copy whose `blind-reads.json` is exactly `{"runner_invocations": [{"entry": "scripts/blind.sh", "args": ["test"], "prefix": "tests"}]}`. `PLANS` is a copy whose `blind-reads.json` is exactly that same text with the value of `prefix` replaced by the plans lane directory, `docs/gauntlet/plans`. The three keys are the declaration: `entry` is the entry path, `args` the fixed argument words that follow it, `prefix` the path prefix its one remaining argument sits under.

The payload families below are not typed. A fixture generates a listing: names it invents at run time, of which some sit under `tests` and the rest under lane directories and under `.claude/hooks`, and the family is one payload per listed name.
